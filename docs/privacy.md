# gmail-multi privacy policy

gmail-multi is a personal tool used only by its owner. It accesses Gmail data only for accounts the owner
explicitly connects, only to answer the owner's own requests through their AI assistant.
Refresh tokens are stored encrypted in the owner's Google Cloud Secret Manager. No data is sold, shared,
or used for advertising or model training. Access can be revoked at any time at
https://myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy,
including the Limited Use requirements.
